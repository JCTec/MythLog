## Description (max 4,000 characters)

What happened while you were away?

Your Mac already knows: the screen unlocked, the machine woke, apps launched, files changed. MythLog turns those signals into a readable, trustworthy history — a live timeline you can scroll, filter, and search.

A LIVE SECURITY TIMELINE
MythLog's background recorder captures meaningful local events the moment they happen: screen lock and unlock, sleep and wake, app launches and focus changes, changes to files you choose to watch, and recorder health heartbeats. The timeline shows them left to right, with filters to prioritize what matters and an inspector for the details of every event.

TAMPER-EVIDENT BY CONSTRUCTION
Every event is written to an append-only ledger where each record is cryptographically chained to the one before it (HMAC-SHA256). If anything is altered, deleted, or reordered, verification fails and MythLog tells you. The chain head is also anchored to your iCloud Drive, so even truncating the ledger is detectable. You can export a verifiable proof bundle at any time.

PRIVATE BY DESIGN
Everything stays on your Mac. No account, no cloud service, no analytics. MythLog never logs keystrokes, never takes screenshots, never records your microphone, and never reads your messages or browsing. The recorder is a visible login item you install, see, and remove yourself — consent first, always.

BUILT FOR TINKERERS
Your own scripts and tools can add events to the timeline through a simple command-line interface — backup jobs, audio detectors, custom security checks, anything. MythLog is written in pure Swift, and its source is available for you to read and audit yourself.

WHAT IT RECORDS
• Screen lock and unlock
• Sleep, wake, and display events
• App launch, activation, and termination
• Changes to files and folders you choose
• Your own custom events via CLI
• Recorder health and ledger integrity

Requires macOS 14 or later.

## Notes

- Promotional text can be changed anytime without submitting a new build.
- Keyword list is carried over unchanged through the rename.
- Description and promotional text say "source available," not "open
  source" — the project moved off the MIT License to the MythLog Personal
  Use License (see repo root `LICENSE`), which permits personal copying and
  modification but not redistribution or commercial use. Do not reintroduce
  "open source"/"MIT" language in App Store copy.
- One thing to weigh before submitting: App Store Connect already indexes the
  app name, so keywords that repeat a word in it are wasted budget. "MythLog"
  contains **log**, and `log` is still in the list. Dropping it would free 4
  characters for a term the name does not already cover. Left in place here
  because the keyword set was specified as unchanged — this is a deliberate
  call for a human, not an oversight.
- "mac" remains available as a keyword; it is not part of the app name.
- Screenshots live in `DesignAssets/AppStoreScreenshots/`, generated by the
  Pillow script (regenerate after UI changes to the branding assets).
